# Сравнение методов интерполяции GPS-треков парусных гонок

Исследовательская часть моей бакалаврской работы (4 курс). Здесь я сравниваю пять методов интерполяции на реальных GPS-треках с регат и выясняю, какой из них лучше подходит для восстановления пропущенных координат.

## Методы

- Линейная интерполяция
- Полином Лагранжа
- Кубический сплайн
- Эрмитов сплайн
- B-сплайн

## Структура репозитория

```
notebooks/           — Jupyter-ноутбуки с экспериментами
  01_data_exploration        — разведочный анализ треков
  02_methods_demo            — визуализация работы каждого метода
  03_accuracy_experiment     — эксперимент по точности (holdout-тест)
  04_performance_experiment  — замер производительности
  05_results_summary         — итоговые таблицы и графики для диплома
src/interp_research/ — пакет с реализациями методов, метриками и утилитами
data/                — GPX-файлы треков
results/             — CSV-таблицы и PNG-графики для главы 3
tests/               — тесты (кросс-проверка своих реализаций против scipy)
```

## Как запустить

```bash
uv sync
uv pip install -e .
jupyter notebook
```

Ноутбуки пронумерованы — можно запускать по порядку, каждый работает через «Restart Kernel and Run All».

## Стек

Python 3.11+, NumPy, SciPy, Matplotlib, Pandas, gpxpy. Управление зависимостями — uv.
